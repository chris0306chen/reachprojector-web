# Video 1 — Measure First, Buy Second

**Length:** 30-40 seconds

**Hook:**

Buying a projector? The model number is not your first decision.

**Shot list and script:**

1. Tape measure across the wall: “Start with the image size you actually want.”
2. Measure projector position: “Then measure the real lens-to-screen distance—not the back of the projector.”
3. Show window and room lights: “Decide how much ambient light you will really have.”
4. Show seating and sound equipment: “Check viewing distance, mounting position and your audio connection.”
5. Show a distorted test image: “Digital correction can make setup easier, but it cannot fix every bad placement without a trade-off.”
6. Show a simple checklist: “Send us these measurements before choosing a model. It can prevent the most expensive projector mistake.”

**On-screen checklist:** Screen size / Throw distance / Ambient light / Mounting / Audio

**Caption:**

The best projector on paper can still be the wrong projector for your room. Save this checklist before you buy.

**CTA:** Send your room measurements for a compatibility check.

# Video 2 — The UST Return Checklist

**Length:** 35-45 seconds

**Hook:**

Before buying an ultra-short-throw projector, check these five things—or risk an expensive return.

**Shot list and script:**

1. UST beside screen: “First: your screen. UST projectors need a very flat, correctly installed surface.”
2. Bright object on dark background: “Second: check whether you are sensitive to rainbow effect or laser speckle.”
3. Measure cabinet depth and screen height: “Third: make sure the cabinet position can create your target image size.”
4. Show settings and app icons without claiming certification: “Fourth: confirm the exact regional system and the apps you need.”
5. Quiet room and return label: “Fifth: listen for fan noise and test everything before the return window closes.”

**On-screen checklist:** Screen / RBE & speckle / Cabinet / Regional system / Return window

**Caption:**

UST can deliver an incredible large-screen experience, but room fit matters more than headline specifications.

**CTA:** Save this before comparing PX3-Pro, L9Q, Formovie or Aetherion.
